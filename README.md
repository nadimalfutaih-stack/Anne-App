# Meine Expedition – Instagram-Auftritt und Investor-Pitch

Dieses Repository ist die geordnete Sammelstelle für alles, was Nadim für Filme, Werbevideos und Pitches braucht.

- **Fokus 1:** Instagram-Auftritt. **Fokus 2:** Pitch für Investoren. Alles andere kommt später.
- **Das Produkt:** „Meine Expedition“ ist ein gedrucktes, persönliches Lern-Abenteuerbuch für Grundschulkinder.
- **Merksatz:** „Der Schulstoff deines Kindes. Sein eigenes Abenteuer. Ein Freund, der mitwächst.“
- **Getrennt vom Generator:** Der Generator-Code liegt in einem anderen Repository und wird hier nicht angefasst.
- **Nur Texte und Links:** Videos, Bilder und Druck-PDFs bleiben in Google Drive.
- **Keine Daten echter Kinder.** Als Beispiel dient nur das Musterbuch DEMO-01.
- **Arbeitsregeln:** stehen in `CLAUDE.md`.
- **Offene Fragen an Nadim:** stehen in `OFFEN.md`. **Beschlüsse:** stehen in `ENTSCHEIDUNGEN.md`.
- **Für Moritz (Technik):** der Aufbauplan liegt in `06_aufbauplan-moritz/`.
