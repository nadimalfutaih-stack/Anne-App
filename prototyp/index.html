Entwurf mit Beispieleinträgen. Annes echte Termine kommen später direkt aus ihrem iCloud-Kalender.

Hallo Anne

So funktioniert es

  1. Anne trägt wie gewohnt alles in ihren Kalender ein.
  2. Alle paar Minuten holt das Dashboard neue Einträge ab.
  3. Jeder Eintrag bekommt automatisch eine Kategorie und eine Dringlichkeit.
  4. Abhaken geht hier. Der Kalender selbst bleibt unverändert.

Unter jedem Eintrag steht, woran die Kategorie erkannt wurde. So sieht man sofort, wenn etwas falsch einsortiert ist.
